# 🎮 Píldora Formativa: Feature Engineering  
### La Fábrica de Juguetes del Data Analyst

Esta píldora formativa introduce el concepto de **Feature Engineering** a través de una metáfora visual y divertida: una **fábrica de juguetes** donde los datos crudos se transforman en características útiles para entrenar modelos de Machine Learning.

---

## 🧸 Objetivo de la píldora  

- Qué es el **feature engineering** y por qué es tan importante.
- Cómo transformar datos crudos en características útiles.
- Cómo crear features en Python usando pandas.
- Cómo entrenar un modelo de clasificación simple.
- Cómo justificar sus decisiones como analista.

## 🧠✨ ¿Qué aprenderás en esta píldora formativa?

En esta sesión te convertirás en un **Ingeniero de Juguetes**, capaz de transformar datos crudos en información poderosa para un modelo de Machine Learning. A lo largo de la píldora aprenderás:

### 🔧 1. Qué es el Feature Engineering  
Entenderás por qué transformar los datos es tan importante como elegir el modelo.  
Descubrirás cómo convertir datos simples en **pistas inteligentes** que ayudan al algoritmo a aprender mejor.

### 🏭 2. La metáfora de la Fábrica de Juguetes  
Verás cómo los datos pasan por distintas fases:  
- **Materia prima** → datos crudos  
- **Taller del ingeniero** → creación de nuevas features  
- **Control de calidad** → selección de las mejores  
- **Máquina ML** → predicción de superventas  

### 🧪 3. Crear features en Python  
Aprenderás a usar pandas para:  
- combinar columnas  
- crear variables categóricas  
- generar indicadores binarios  
- detectar patrones ocultos  
- transformar datos en información útil  

### 🤖 4. Entrenar un modelo de Machine Learning  
Usarás scikit‑learn para:  
- preparar los datos  
- dividir en train/test  
- entrenar un clasificador  
- evaluar su rendimiento  

### 🎯 5. Justificar tus decisiones como analista  
Explicarás por qué creaste cada feature y cómo mejora el modelo.  
Este paso es clave para pensar como un **Data Analyst profesional**.


### Al final de la píldora, habrás recorrido todo el camino: **desde los datos crudos hasta una predicción real**, pasando por decisiones creativas y técnicas.

## 🧩 Entorno Virtual: Preparación del Taller

Antes de empezar a trabajar con el notebook, vamos a crear un **entorno virtual**.  
Esto nos permite instalar las librerías del proyecto sin afectar al resto del sistema.

### 🔧 1. Crear el entorno virtual

```bash
python -m venv venv
```  
### 🚀 2. Activar el entorno virtual  
🔹 En Windows
```bash
venv\Scripts\activate
```  
🔹 En macOS / Linux
```bash
source venv/bin/activate
```  
Cuando veas (venv) al inicio de tu terminal, significa que está activado.

### 📦 3. Instalar las dependencias del proyecto
```bash
pip install -r requirements.txt
```  
Esto instalará pandas, numpy, matplotlib, seaborn, scikit‑learn y jupyter.

### 📴 5. Desactivar el entorno cuando termines
```bash  
deactivate
```
